# Story 3.1 — Tasks de Governança do @kairos

**Epic:** 3 — Governança e Versionamento
**Status:** Done
**Complexidade:** G
**Criada por:** @kairos
**Data:** 2026-04-06

---

## Objetivo

Implementar as tasks de governança que tornam o `@kairos` operacional: criar stories, criar squads, versionar, inspecionar status, revisar stories com gates PASS/BLOCK, e controlar git push de forma exclusiva.

---

## Critérios de Aceite

- [x] `kairos-new-story.md` — cria `docs/stories/{epic}.{N}.story.md` com elicitação guiada e atualiza README + epic
- [x] `kairos-new-squad.md` — scaffolda estrutura completa de novo squad e atualiza core-config + epic 4
- [x] `kairos-version-bump.md` — valida bump type, exige story para MINOR/MAJOR, atualiza core-config + CHANGELOG
- [x] `kairos-status.md` — agrega versão, squads, stories abertas, último changelog, gates recentes, handoffs não consumidos
- [x] `kairos-review.md` — valida ACs de uma story, calcula quality_score, emite gate PASS/BLOCK em `docs/qa/gates/`
- [x] `kairos-pre-push.md` — verifica consistência de versão, gates ativos, referências quebradas; seta `pre_push_passed=true`
- [x] `kairos-push.md` — executa `git push` apenas se `pre_push_passed=true` na sessão atual

## Fora de Escopo

- Automação de CI/CD (hook de pré-commit é story 3.2, candidata)
- `*status` integrado com métricas operacionais dos squads

## Dependências

- `@kairos` persona criada em `.claude/commands/kairos/agents/kairos.md`
- `docs/qa/gates/` diretório criado
