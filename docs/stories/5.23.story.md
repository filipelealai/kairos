## Objetivo

Corrigir em todos os arquivos framework-managed a afirmação falsa de que `ANTHROPIC_API_KEY` é um pré-requisito universal do Kairos: o framework roda dentro do Claude Code (que gerencia seu próprio acesso à API) e não depende da chave — ela é necessária apenas quando scripts de instância fazem chamadas diretas à API Anthropic via `@anthropic-ai/sdk`.

> **Bump:** PATCH — correção em `owned_sections` (`.env.example`) e arquivos L2/L3 (`push-dual.md`, `CHANGELOG.md`). O sha256 do bloco `ai-providers` no `manifest.yaml` será atualizado pelo `*pre-push`.

## Critérios de Aceite

- [x] `.env.example` bloco `ai-providers` (framework-managed): cabeçalho do arquivo corrigido — remover "All variables are optional except ANTHROPIC_API_KEY" → "All variables are optional"
- [x] `.env.example` bloco `ai-providers`: comentário da variável corrigido — `# Anthropic (required — default model engine)` → `# Anthropic (optional — needed only if your agent scripts make direct API calls via @anthropic-ai/sdk)`
- [x] `CONTRIBUTING.md` seção "Rodar a instância como usuário": linha "Preencher ANTHROPIC_API_KEY e demais variáveis relevantes" substituída por instrução que esclarece que todas as variáveis do `.env` são opcionais e dependem da stack e integrações configuradas na instância
- [x] `squads/ops/tasks/push-dual.md`: localizar e corrigir ocorrência de "All variables are optional except ANTHROPIC_API_KEY" → "All variables are optional"
- [x] `CHANGELOG.md`: localizar a entrada histórica que contém "todos opcionais exceto ANTHROPIC_API_KEY" — adicionar nota de rodapé inline `(corrigido em v{versão-desta-story}: a chave é opcional)` sem reescrever o registro histórico
- [x] Após editar o bloco `ai-providers` do `.env.example`, confirmar que o sha256 correspondente em `manifest.yaml` (`owned_sections[.env.example][ai-providers]`) será atualizado pelo `*pre-push` (não atualizar manualmente)
- [x] Busca final: grep por "ANTHROPIC_API_KEY" em todos os arquivos framework-managed (owned_files + owned_sections + sync_files listados no manifest) — qualquer ocorrência remanescente que afirme "required" ou equivalente deve ser corrigida ou documentada como falso positivo no Execution Log
