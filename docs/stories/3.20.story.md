## Objetivo

Investigar por que o `README.md` não é atualizado durante o bump de versão no `*pre-push`, mesmo após um patch anterior ter sido aplicado para isso, e corrigir definitivamente o passo de bump.

## Critérios de Aceite

- [x] AC1: Rastrear no git/stories o patch anterior que tentou incluir o `README.md` no bump — causa raiz de por que não funcionou identificada e documentada no Execution Log
- [x] AC2: `kairos-pre-push.md` e/ou `kairos-version-bump.md` corrigidos para incluir atualização do `README.md` no passo de bump de versão
- [x] AC3: Teste manual confirma que após o fix, `README.md` reflete a nova versão após um *pre-push com bump PATCH

### O que foi feito

- Investigado o git log para rastrear o patch anterior relacionado ao README.md no bump de versão
- Identificada a causa raiz: o bump inline do Passo 2 em `kairos-pre-push.md` estava desincronizado com `kairos-version-bump.md` — o step de atualizar README.md nunca foi replicado para o inline bump
- Adicionado passo `**e.**` no bump inline (Passo 2) de `kairos-pre-push.md` para atualizar `README.md` (localizando linha `**Versão atual:**` e substituindo a versão)
- Renomeado o antigo passo `**e.** Confirme` para `**f.**` para acomodar o novo step
- Atualizada referência em step 4.e de `2.a–2.e` para `2.a–2.f`
- Corrigido o drift acumulado: `README.md` atualizado manualmente de `3.1.1` para `3.1.8` (versão atual)

### Decisões tomadas

- **Onde adicionar o fix — pre-push vs version-bump:** `kairos-version-bump.md` já tinha o passo de README corretamente. O fix foi aplicado apenas em `kairos-pre-push.md` (o bump inline), que é o caminho que realmente executa durante o `*pre-push`. Não há duplicação de fix.
- **Atualização do drift acumulado:** o README estava em `3.1.1` enquanto a versão real é `3.1.8` — 7 bumps sem atualização. Corrigido como parte do AC3 (verificação manual do formato e da linha alvo).
