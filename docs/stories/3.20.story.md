## Objetivo

Investigar por que o `README.md` não é atualizado durante o bump de versão no `*pre-push`, mesmo após um patch anterior ter sido aplicado para isso, e corrigir definitivamente o passo de bump.

## Critérios de Aceite

- [ ] AC1: Rastrear no git/stories o patch anterior que tentou incluir o `README.md` no bump — causa raiz de por que não funcionou identificada e documentada no Execution Log
- [ ] AC2: `kairos-pre-push.md` e/ou `kairos-version-bump.md` corrigidos para incluir atualização do `README.md` no passo de bump de versão
- [ ] AC3: Teste manual confirma que após o fix, `README.md` reflete a nova versão após um *pre-push com bump PATCH
