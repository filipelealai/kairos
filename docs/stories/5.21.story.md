## Objetivo

Atualizar os blocos `KAIROS-MANAGED` do `CLAUDE.md` para remover hardcodes TypeScript que os transformam em instruções universais incorretas: TypeScript é o runtime da instância atual, não uma propriedade do framework — o framework é markdown + YAML + CJS.

> **Bump:** PATCH — correção em `owned_sections`. Os sha256 dos blocos no `manifest.yaml` serão atualizados pelo `*pre-push` automaticamente.

## Critérios de Aceite

- [x] Bloco `framework-conventions`: bullet "**Agentes TypeScript** — computação pura para tarefas específicas de cada squad" → "**Scripts de agentes** — computação pura para tarefas específicas de cada squad (linguagem definida pela stack da instância)"
- [x] Bloco `framework-conventions`, seção Stack: remover referências hardcoded pressupondo stack TypeScript; o framework core é markdown + YAML + CJS (verificar `README.md` após implementação da story 5.20)
- [x] Bloco `kairos-core`, seção "Estrutura Kairos Core": substituir todo o conteúdo pela estrutura real para `.kairos-core/`, `.claude/`, `.github/` (como na seção "Estrutura" em `README.md` após implementação da story 5.20)
- [x] Seções user-owned do CLAUDE.md (abaixo do último `KAIROS-MANAGED-END`) permanecem intactas — zero modificações fora dos blocos managed
- [x] Após editar os blocos, confirmar que os sha256 no `manifest.yaml` serão atualizados pelo `*pre-push` (não atualizar manualmente — é responsabilidade do `*pre-push` Passo 2.7)
