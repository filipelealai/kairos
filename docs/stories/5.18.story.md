## Objetivo

Habilitar branch protection rules na branch `main` de `filipelealweb/kairos` (remote `origin`) para garantir que PRs de contribuidores externos passem por review antes de merge, sem bloquear o fluxo de push-dual do mantenedor.

## Critérios de Aceite

- [x] Branch protection está habilitada na branch `main` de `filipelealweb/kairos` via `gh api`
- [x] `enforce_admins: false` — admins (incluindo o mantenedor) podem fazer push direto, preservando o fluxo push-dual
- [x] PRs de não-admins exigem ao menos 1 review aprovado antes de merge (`required_approving_review_count: 1`)
- [x] CODEOWNERS review é exigido (`require_code_owner_reviews: true`) — depende de 5.17 Done
- [x] Dismiss stale reviews está habilitado — aprovações invalidadas quando novos commits são pushados
- [x] Force pushes para `main` são bloqueados (`allow_force_pushes: false`)
- [x] Deletions de `main` são bloqueados (`allow_deletions: false`)
- [x] Se 5.19 (CI validate-manifest) estiver Done no momento da execução: `validate-manifest.yml` adicionado como required status check; se ainda Draft, `required_status_checks: null` com nota no Execution Log

## Fora de Escopo

- Configuração de branch protection no repo privado `filipelealweb/kairos-pessoal` (remote `private`)
- Alterações no fluxo de push-dual — `enforce_admins: false` garante compatibilidade; nenhuma mudança no Kairos é necessária
- Required status checks do CI (5.19) — pode ser adicionado após 5.19 Done via update desta configuração
- Configuração de branch protection em branches além de `main`

## Dependências

- 5.17 (`.github/` Scaffold — CODEOWNERS) — Done ✅
- 5.19 (CI: Validação de Manifest em PRs) — Draft; required status check opcional nesta execução

## Notas de Implementação

Executar via `gh api`:

```bash
gh api repos/filipelealweb/kairos/branches/main/protection \
  --method PUT \
  --header "Accept: application/vnd.github+json" \
  --input - << 'EOF'
{
  "required_status_checks": null,
  "enforce_admins": false,
  "required_pull_request_reviews": {
    "dismiss_stale_reviews": true,
    "require_code_owner_reviews": true,
    "required_approving_review_count": 1
  },
  "restrictions": null,
  "allow_force_pushes": false,
  "allow_deletions": false
}
EOF
```

Se 5.19 estiver Done, substituir `"required_status_checks": null` por:
```json
"required_status_checks": {
  "strict": true,
  "contexts": ["validate-manifest"]
}
```

Verificar após execução:
```bash
gh api repos/filipelealweb/kairos/branches/main/protection
```
