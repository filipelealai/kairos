## Objetivo

Integrar o `*doctor` (health check completo) no `*pre-push` como Passo 0, tornando o `*pre-push` o único motor de validação antes de qualquer saída — PR ou push. Elimina a redundância do fluxo atual (`*doctor` → `*pre-push`) e segue o princípio IDS (REUTILIZAR em vez de CRIAR): nenhum novo comando criado, `*doctor` reaproveitado como suíte de checks do primeiro passo.

O `*doctor` permanece inalterado como health check standalone para uso operacional. O `*pre-push` passa a incorporá-lo internamente.

**Fluxo resultante — igual para contribuidor e mantenedor:**

```
*review → *pre-push → PR  (contribuidor sem acesso de push)
*review → *pre-push → *push  (mantenedor)
```

## Critérios de Aceite

## Notas para o executor

A integração é cirúrgica: substituir o Passo 0 atual (`kairos-pre-push.md`) por "Executar `*doctor` e avaliar veredicto". O resto da task permanece idêntico. A única lógica nova é o mapeamento de veredicto do `*doctor` para PASS/BLOCK no contexto do `*pre-push`:

```
*doctor HEALTHY   → prosseguir
*doctor WARNING   → prosseguir (warnings listados no sumário), exceto WARNs de manifest integrity → BLOCK
*doctor CRITICAL  → BLOCK imediato
```

`CONTRIBUTING.md` e `.github/PULL_REQUEST_TEMPLATE.md` foram modificados manualmente com referências a `*ci` que **não deve existir** — essas edições devem ser revertidas/corrigidas para `*pre-push`.
