## Objetivo

Criar `CONTRIBUTING.md` na raiz do projeto com regras de contribuição adaptadas do `SynkraAI/aiox-core` para a realidade do Kairos. O conteúdo deve refletir que o framework é **stack-agnóstico** (markdown + yaml + cjs — não exige Node para contribuir), que o gate de qualidade atual é **local via `*doctor` + `*review`** (CI em GitHub Actions é follow-up da story 5.19), e que contribuições precisam respeitar a **fronteira framework/instância via manifest.yaml**.
