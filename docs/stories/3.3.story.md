## Objetivo

Dois ajustes de UX sem dependências entre si, mas que atualizam as mesmas docs: remover o argumento `"título"` do `*new-story` (a elicitação já é guiada — o argumento é um resquício) e atualizar `*help` e a persona para refletir o novo fluxo do `*pre-push` (story 3.2) e o `*new-story` revisado.

---

## Critérios de Aceite

- [x] `kairos-new-story.md` — campo `title` removido de `Entrada`; elicitação começa sempre perguntando "Qual epic?"; lista os epics disponíveis (lendo `docs/epics/`) para ajudar o usuário a escolher
- [x] `kairos-new-story.md` — ID da story gerado automaticamente: @kairos lê `docs/stories/` e conta as stories do epic escolhido para determinar o próximo número (`{epic}.{N}`)
- [x] `kairos-new-story.md` — formato de saída do arquivo alinhado com `story-template.md` (resolver drift: a task usava "Dev Agent Record / Completion Notes"; o template usa "Fora de Escopo / Dependências / Change Log")
- [x] `kairos-help.md` — Seção 2 (comandos): assinatura de `*new-story` corrigida (sem argumento); descrição de `*version` atualizada (comando avulso, bump padrão ocorre via `*pre-push`); `*pre-push` expandido para mencionar versão + commit
- [x] `kairos-help.md` — Seção 3 (fluxos): Fluxo ③ atualizado: `*pre-push` trata versão + commit; `*version` sai do fluxo padrão obrigatório
- [x] Persona `kairos.md` — assinatura do comando `*new-story` sem argumento; nota em `*version` indicando que o bump padrão ocorre via `*pre-push`
