## Objetivo

Reescrever `.kairos-core/docs/data-flow.md` e atualizar `.kairos-core/docs/agent-standards.md` para refletir o estado real do framework v3.9.x — eliminando referências de instância apresentadas como convenção, documentando a arquitetura de duas camadas (scripts + IA), corrigindo paths e completando o padrão de persona com o wrapper markdown que estava ausente.

## Contexto

Ambos os arquivos estão defasados após extensa evolução do framework:

- `data-flow.md` tem `kairos-version: 2.0.0`. Assume padrões de instância como convenções do framework (`emails/` como tipo de output), omite a camada de scripts, referencia path errado (`docs/` em vez de `workflows/`), não menciona `workflow-chains.yaml`, e não reflete a separação framework/usuário da constituição VI.21.
- `agent-standards.md` tem `kairos-version: 3.7.0`. Documenta apenas o bloco YAML interno da persona, sem o wrapper markdown obrigatório (ACTIVATION-NOTICE, CRÍTICO, seções `## Comandos Rápidos` / `## Guia` / footer). Também omite o bloco `IDE-FILE-RESOLUTION` e descreve `devLoadAlwaysFiles` de forma imprecisa.

Fonte canônica para comparação: `agent-template.md` (estrutura de persona) e constituição (princípios I.4, IV.13, IV.14, VI.21).

## Critérios de Aceite

- [x] `data-flow.md` reescrito com diagrama de duas camadas (scripts `src/agents/` + agentes IA) explicitando a separação de responsabilidades
- [x] `data-flow.md` sem referências a tipos de output específicos de instância (`emails/`, `reports/` como convenção do framework) — `{tipo}` é definido pelo squad
- [x] `data-flow.md` referencia `squads/{squad}/workflows/data-flow.md` (não `docs/`)
- [x] `data-flow.md` menciona `squads/{squad}/data/workflow-chains.yaml` e seu papel no Step 5.5 do greeting
- [x] `data-flow.md` inclui tabela de responsabilidade de documentação por nível (framework / squad / pipeline)
- [x] `data-flow.md` referencia os princípios corretos da constituição na seção Limites (I.2, I.4, IV.13, IV.14)
- [x] `agent-standards.md` documenta o wrapper markdown completo da persona: frontmatter `kairos-owned`, `ACTIVATION-NOTICE`, `CRÍTICO`, `## COMPLETE AGENT DEFINITION FOLLOWS`, `## Comandos Rápidos`, `## Guia (*guide)`, footer
- [x] `agent-standards.md` documenta o bloco `IDE-FILE-RESOLUTION` como campo obrigatório do YAML interno
- [x] `agent-standards.md` corrige descrição de `devLoadAlwaysFiles`: carregado via `core-config.yaml`, não "pelos agentes"
- [x] Nenhum dos dois arquivos contém referências a squads ou integrações específicas da instância apresentadas como padrão (constituição VI.21)

## Fora de Escopo

- Criar ou atualizar `squads/{squad}/workflows/data-flow.md` para squads existentes
- Modificar personas de agentes existentes
- Corrigir `email-writer` persona (ausência de `dependencies.scripts`) — fora do escopo de documentação de framework
