# Story 2.1: Loop de Disparo — n8n Lê JSON e Dispara E-mails

**Status:** Draft
**Escopo:** cold-prospecting
**Epic:** 2 — Automação de Disparo

---

## Contexto

Com o JSON de e-mails gerado pelo `@email-writer`, o próximo passo é que o n8n leia esse arquivo e execute o disparo. Atualmente o disparo é manual ou desconectado do output do Kairos.

---

## O que precisa ser feito

1. Criar workflow n8n "Kairos — Disparo de E-mails" que:
   - Leia `data/outputs/cold-prospecting/emails/email-writer_emails-YYYY-MM-DD.json` (via HTTP Request ou Webhook trigger)
   - Para cada item não suspeito (`email_suspeito = false`): envie o e-mail via Gmail/SMTP
   - Após envio: atualize `Status do Envio = ENVIADO` na planilha pelo `row_number`
   - Itens suspeitos: pular ou registrar separadamente

2. Configurar rate limiting (ex: máx. 200 e-mails/hora) para evitar spam score

3. Configurar retry em caso de falha de envio

---

## Critérios de Aceite

- [ ] Workflow n8n lê o arquivo JSON do dia atual
- [ ] E-mails são disparados com assunto e corpo corretos
- [ ] `email_suspeito = true` → e-mail não enviado
- [ ] `Status do Envio` atualizado para `ENVIADO` na planilha após cada envio bem-sucedido
- [ ] Falhas de envio registradas (não silenciosas)
- [ ] Rate limiting configurado (≤ 200/hora)

---

## Fora de Escopo

- Tracking de abertura de e-mail
- Respostas automáticas
- A/B testing de assuntos
