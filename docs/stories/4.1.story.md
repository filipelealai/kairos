### Decisões tomadas

- **AC 5 (lifecycle) já estava concluído:** `sales-pipeline-lifecycle.md` já continha estágios do Trello, handoff chain e exemplos de execução parcial desde o scaffolding — não foi necessário adicionar conteúdo
- **Integração Trello via REST direto** (não via MCP): a task orienta o agente a fazer chamadas HTTP diretamente, pois não há MCP de Trello configurado nesta instância. A alternativa seria criar um script TS, mas a autoridade do squad prevê que @call-analyst opera via Claude sem script — REST direto é o caminho correto
- **Env vars para IDs das listas Trello**: escolhido expor como env vars configuráveis em vez de discovery em runtime a cada call, para evitar chamada extra desnecessária em cada *analyze
