# Story 3.9 — Pre-Push: Prompt Opcional de Bump para Stories PATCH

**Epic:** 3 — Governança e Versionamento
**Status:** Draft
**Complexidade:** P
**Criada por:** @kairos
**Data:** 2026-04-16

---

## Objetivo

O `*pre-push` atual só detecta e solicita bump de versão para stories MINOR e MAJOR. Stories PATCH são silenciosamente ignoradas, forçando o usuário a rodar `*version patch` manualmente caso queira registrar o bump — ou deixar sem bump. Adicionar um prompt opcional não-bloqueante para PATCH: "Story PATCH sem bump desde o último release — deseja bumpar agora? (s/n)".

---

## Critérios de Aceite

- [ ] `kairos-pre-push.md` — Passo 2 (versionamento) expandido: após tratar MINOR/MAJOR, verifica se existe story PATCH com gate PASS/RESSALVA sem bump de versão correspondente no `CHANGELOG.md`
- [ ] Se story PATCH sem bump detectada: exibe prompt **não-bloqueante**: "Story {id} é PATCH — sem bump desde o último release. Deseja bumpar agora? (s/n)" — se não: continua normalmente; se sim: executa bump PATCH inline e continua
- [ ] O prompt não aparece se já houve bump PATCH desde o gate da story (verificação por data: data do gate vs data da entrada mais recente no CHANGELOG.md)
- [ ] Stories PATCH sem gate algum (não passaram por *review) não disparam o prompt — o check é condicionado à existência de gate PASS/RESSALVA
- [ ] Comportamento para MINOR/MAJOR permanece inalterado (bloqueante, obrigatório)

## Fora de Escopo

- Tornar o bump PATCH obrigatório (continua opcional — PATCH não exige story nem bump)
- Modificar `kairos-version-bump.md` (sem mudança)
- Exibir o prompt para stories sem gate (apenas stories que passaram por *review)
