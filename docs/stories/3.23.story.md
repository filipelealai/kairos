## Objetivo

Adicionar o argumento `all` ao comando `*validate-story` existente para validar em massa todas as stories abertas (Draft, In Progress, In Review) de uma vez, com relatório consolidado ao final.

## Contexto

Hoje, `*validate-story {id}` opera sobre uma única story por vez. Quando múltiplas stories se acumulam sem validação de formato, o usuário precisa executar o comando individualmente para cada uma. O argumento `all` itera sobre todas as stories abertas e gera um relatório unificado — útil especialmente antes de um `*implement all` ou ao auditar o backlog.

**Nota de implementação:** como não existe campo de estado "já validado" no formato atual das stories, `*validate-story all` revalida todas as stories abertas (idempotente — revalidar não causa dano). O relatório sinaliza stories que já passaram por validação anterior se isso for visível no Change Log.

## Critérios de Aceite

- [x] AC1: `*validate-story all` detecta todas as stories com status `Draft`, `In Progress` ou `In Review` em `docs/stories/`
- [x] AC2: Valida cada story sequencialmente usando o mesmo fluxo de `*validate-story {id}` — sem interrupção entre elas
- [x] AC3: Resultado INVÁLIDA em uma story não interrompe a validação das demais
- [x] AC4: Relatório consolidado ao final: para cada story, resultado (VÁLIDA / RESSALVA / INVÁLIDA) + lista compacta dos problemas encontrados (se houver)
- [x] AC5: Sumário executivo no topo do relatório: total validadas, total VÁLIDA, total RESSALVA, total INVÁLIDA
- [x] AC6: Se nenhuma story aberta for encontrada, exibir mensagem clara
