## Objetivo

A task `kairos-workers.md` hardcoda os nomes dos agentes desta instância (`@campaign-analyst / @lead-scorer / @niche-classifier / @email-writer`) na primeira pergunta da elicitação de `*workers new`. Isso é um acoplamento à instância que quebra o Kairos instalado do zero. Corrigir para leitura dinâmica de `core-config.yaml`.

---

## Critérios de Aceite

- [ ] `kairos-workers.md` — Bloco 1, Pergunta 1 atualizada: em vez de listar agentes hardcoded, ler `core-config.yaml → agents.squads` e construir a lista dinamicamente no formato `@{agent-id} (squad: {squad-name})` para cada agente registrado
- [ ] Se `core-config.yaml` não tiver nenhum squad registrado com agentes: exibir "Nenhum agente registrado. Adicione squads via `*new-squad` antes de criar workers." e HALT
- [ ] A pergunta exibida ao usuário inclui a lista dinâmica como sugestão, mas aceita qualquer resposta — o usuário pode informar um agente não listado (ex: agente em desenvolvimento ainda não registrado no config)
- [ ] Nenhuma outra parte da task é alterada

## Fora de Escopo
