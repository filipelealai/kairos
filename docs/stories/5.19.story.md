## Objetivo

Criar o primeiro workflow de GitHub Actions do Kairos — `.github/workflows/validate-manifest.yml` — que executa, em PRs contra `main`, o subset determinístico dos checks de `*doctor` relacionados a ownership. Oferece gate automático para contribuições externas (onde o mantenedor não roda `*doctor` localmente antes do merge). Stack-agnóstico: bash + yq + shasum + grep, zero Node.

## Critérios de Aceite

- [ ] `.github/workflows/validate-manifest.yml` criado — dispara em `pull_request` contra `main`.
- [ ] Script de validação decidido durante execução:
  - (a) embutido no workflow (inline bash); **ou**
  - (b) arquivo separado em `.github/scripts/validate-manifest.sh` invocado pelo workflow
- [ ] Checks implementados (subset determinístico do `*doctor`):
  - [ ] Cada `owned_files[*].path` declarado em `.kairos-core/manifest.yaml` existe no tree do PR.
  - [ ] Cada `owned_files[*].sha256` bate com `shasum` real do arquivo (exceto `self-referential`). Divergência = FAIL (diferente do `*doctor` local que é WARN — CI é mais rígido).
  - [ ] Arquivos `.md` com frontmatter `kairos-owned: true` que não estão em `owned_files` = WARN (não bloqueia).
  - [ ] Arquivos `.md` em `owned_files` sem frontmatter `kairos-owned: true` = WARN.
  - [ ] Markers `<!-- KAIROS-MANAGED-START: {name} -->` ... `<!-- KAIROS-MANAGED-END: {name} -->` emparelhados em `owned_sections[*]` do tipo `markdown_blocks` (FAIL se desemparelhado ou órfão).
  - [ ] Cada `sync_files[*].path` existe (FAIL se ausente).
- [ ] Output formatado para leitura humana no GitHub Actions Summary (tabela de checks ou listagem estruturada).
- [ ] Stack do workflow: bash + yq (via `mikefarah/yq` ou setup action) + coreutils `sha256sum` — zero dependência de Node, TypeScript, ou framework Kairos rodando.
- [ ] Manifest atualizado: workflow (e script, se externo) como `owned_files` (L3) com sha256.
- [ ] `squads/ops/tasks/push-dual.md` Passo 2a atualizado com os novos paths.
- [ ] Testado localmente antes do merge: rodar o script contra o tree atual e contra um estado artificialmente corrompido (drift de sha, arquivo faltando) para validar FAIL/WARN corretos.
- [ ] Bump MINOR em `.kairos-core/core-config.yaml` (primeira capacidade de CI) + entry em `CHANGELOG.md`.
- [ ] `@kairos *doctor` passa após a implementação.

## Fora de Escopo
