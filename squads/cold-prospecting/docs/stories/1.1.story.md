# Story 1.1: Webhook de Leads — Acesso aos Dados via n8n

**Status:** Done
**Escopo:** cold-prospecting
**Epic:** 1 — Infraestrutura de Dados

---

## Contexto

Kairos precisava de acesso aos 22k+ leads armazenados no Google Sheets do Vendoteca sem dependência de autenticação OAuth direta. O n8n já tinha uma conta de serviço Google autenticada para ler a planilha. A solução foi criar um webhook GET no n8n que funciona como proxy read-only.

---

## O que foi feito

1. Criado workflow n8n "Kairos — GET /leads" (ID: `UwpAZtFejzqUqTxu`)
2. Webhook configurado em `https://n8n.vendoteca.com/webhook/kairos-leads` (GET)
3. Nó Google Sheets lê a aba LEADS (gid=0) da planilha de produção
4. Nó Aggregate agrupa todos os itens em `{ leads: [...] }`
5. Workflow ativado via REST API com JWT

---

## Critérios de Aceite

- [x] GET no webhook retorna `{ leads: [...] }` com todos os registros
- [x] Campos disponíveis: CNPJ, Nome, Nome Fantasia, Email, Atividade Principal, Status do Envio, Pode disparar, Cidade, Estado, Capital Social, Situação
- [x] Webhook sem autenticação (acesso interno apenas)
- [x] Workflow ativo e funcional

---

## Fora de Escopo

- Webhook de escrita (Kairos é read-only nos dados de leads)
- Paginação (retorna todos os registros de uma vez — aceitável para 22k)
