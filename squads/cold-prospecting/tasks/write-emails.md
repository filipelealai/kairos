# Task: write-emails

**Squad:** cold-prospecting
**Agente:** @email-writer (Eva)
**Comando:** `*write N`

Gera N e-mails personalizados para leads pontuados e classificados, aplicando os gates de
qualidade (reconhecimento, sem travessão duplo, abertura não genérica, CTAs variadas). Salva
batch em `data/outputs/cold-prospecting/emails/email-writer_emails-{INSTANCE}-YYYY-MM-DD.json`.
